# Tomea's Wine & Beer

A Minecraft **26.1.2 (Fabric)** mod that adds **5 brewable liquors**, custom `32×32` bottle textures, global server drinking announcements, and a **27-slot Beer Crate** storage block.

## Features
- **5 Custom Beverages:** Wine, Beer, Whiskey, Brandy, and Vodka with custom `32×32` bottle sprites.
- **Server Chat Broadcasts:** Announces `[Player] got drunken by [Liquor]` in chat whenever a player finishes drinking.
- **27-Slot Beer Crate:** Stores up to 27 bottles (1 bottle per slot) to organize bars, taverns, and cellars.

## Brewing & Crafting Recipes

### Brewing Stand

| Beverage | Base | Ingredient |
| :--- | :--- | :--- |
| **Wine** | Water Bottle | Sweet Berries |
| **Beer** | Water Bottle | Wheat |
| **Whiskey** | Beer | Sugar |
| **Brandy** | Wine | Sugar |
| **Vodka** | Water Bottle | Poisonous Potato |

### Beer Crate (Crafting Table)
Surround **1 Chest** in the center with **8 Wooden Planks** (any wood type).

## Requirements
- **Minecraft:** 26.1.2
- **Mod Loader:** Fabric Loader
- **Dependency:** Fabric API
